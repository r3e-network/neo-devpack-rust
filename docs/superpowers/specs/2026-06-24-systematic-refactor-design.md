# Systematic Refactor of neo-rust-devpack — Master Design

**Status:** Approved-in-principle 2026-06-24 · **Execution mode:** Fully autonomous, phase-gated commits
**Evidence base:** [`docs/audit-2026-06-24-findings.md`](../audit-2026-06-24-findings.md) (40 ranked findings)
**Target:** Neo N3 3.9.1 · Workspace v0.5.8 → next minor

---

## 1. Goals

1. **Correctness first.** Eliminate every Tier-1 (Critical) correctness and
   security defect, proven by *executing* generated bytecode — not by opcode
   shape-matching.
2. **Make the devpack wasm32 path real.** A NEP-17 token compiled through this
   SDK must actually emit correct notifications, read its script hash, verify
   signatures, and export ByteString/String entry points.
3. **Make cross-chain honest.** Move and Solana paths either produce correct
   results for the subset they claim or fail loudly at compile/translation time.
4. **Professionalize.** CI supply-chain hygiene, accurate docs, deterministic
   release tooling.

## 2. Non-goals (explicitly out of scope this engagement)

- Full Wasm feature coverage (floats, SIMD, multi-memory, multi-value returns).
- Full Move feature parity (structs/vectors/generics) or real Ed25519 host
  crypto for Solana. These become loud `bail!`/`compile_error!` instead.
- NeoVM gas-model integration.
- Public API stability — **breaking changes are permitted** to fix correctness
  (per approved decision §3.3). Affected APIs get a migration note in CHANGELOG.

## 3. Confirmed design decisions

| # | Decision | Choice |
|---|----------|--------|
| D-1 | Verification harness | **Both**: a minimal in-process Rust NeoVM executor (the emitted-opcode subset) for ms-fast unit tests, **and** Neo Express for end-to-end syscall fidelity. |
| D-2 | Cross-chain stance | **Correct-or-fail-loud**. Unsupported features become explicit errors, never silent wrong answers. Parity is out of scope. |
| D-3 | Breaking changes | **Allowed** to fix correctness. Contract structs become documented-stateless; standalone `#[neo_method]` becomes export-or-`compile_error!`; storage miss vs empty is tightened. |
| D-4 | Autonomy | One approval here + one on the plan; then execute all phases A→E end-to-end. |
| D-5 | Syscall lowering contract | Every public devpack syscall wrapper either has a dedicated wasm import that the translator lowers to a real `SYSCALL`, **or** is removed/`compile_error!`. No silent-default stubs. |

## 4. Phase architecture & ordering

```
Phase A (compiler + exec harness) ──┬──► Phase B (devpack wasm32)
                                    │
                                    ├──► Phase C (contract security)  [may run early; host-mockable]
                                    │
                                    └──► Phase D (cross-chain, fail-loud)

Phase E (professionalization)  last  (CI/docs/release)
```

- **A is foundational**: the exec harness built in A becomes the verification
  substrate for B and D. C is largely host-mockable and may interleave.
- Each phase ships as a series of atomic commits, each = fix + test, `cargo test`
  green before the next. CHANGELOG entry per phase boundary.

## 5. Phase A — Compiler correctness, conformance & execution harness

**Crate:** `wasm-neovm`. **Findings:** T1, T2, T3, C1, C2, C3, C4, C5.

### 5.1 NeoVM execution harness (enables all phases)

**What:** A new in-process executor, gated behind a `testing`/`exec` cargo
feature, that runs a generated `script: &[u8]` against a virtual `ExecutionEngine`
and returns the final stack / fault.

**Scope (implement only what we emit):**
- Stack ops: `PUSH0..PUSHINT256`, `PUSHNULL`, `ISNULL`, `DUP`/`DUPFROMALTSTACK`,
  `SWAP`, `ROT`, `OVER`, `PICK`, `ROLL`, `DEPTH`, `DROP`, `NIP`, `XDROP`,
  `REVERSE3/4/N`, `CLEAR`.
- Arithmetic/bitwise: `ADD/SUB/MUL/DIV/MOD`, `SHL/SHR`, `AND/OR/XOR/INVERT`,
  `SIGN/NEGATE/ABS`, `EQ/NE/LT/LE/GT/GE/MIN/MAX`, `DEC/INC`, `CAT/SUBSTR/LEFT/
  RIGHT` (with BigInt semantics matching NeoVM).
- Locals/control: `INITSLOT`, `LDLOC*/STLOC*`, `LDARG*/STARG*`, `LDSFLD*/STSFLD*`,
  `JMP/JMPIF/JMPIFNOT` + `_L` (1/4-byte offset resolution relative to opcode),
  `CALL_L`, `RET`, `SYSCALL` (dispatch via the existing hash table → pluggable
  host hooks), `CALLT` (resolved against the inferred method-token table),
  `CONVERT`, `NEWARRAY/NEWSTRUCT`, `APPEND`, `SETITEM/PICKITEM`, `SIZE`,
  `ABORT/ASSERT`, `NOP`.
- **Host hooks** for the syscall subset needed by tests: `System.Storage.*`,
  `System.Runtime.{GetTime,CheckWitness,Log,Notify,GetCallingScriptHash,…}`,
  `System.Contract.Call` (mocked). Host state is resettable per-test.
- Deterministic, no I/O, `#![no_std]`-friendly where feasible but std is fine.

**Location:** `wasm-neovm/src/exec/` (`engine.rs`, `stack.rs`, `dispatch.rs`,
`host.rs`) behind `#[cfg(any(test, feature = "exec"))]`. Expose a public
`fn run_script(script, host) -> ExecResult` + an integration-test helper in
`wasm-neovm/tests/support/`.

**Validation:** the executor itself is unit-tested against hand-written
script/expected-stack pairs and cross-checked where possible against Neo Express
for a handful of canonical scripts (so we trust the oracle).

### 5.2 Fixes (each: fix + exec-backed regression test)

- **T1 (store codegen):** rewrite the per-byte tail of
  `emit_memory_store_helper` to leave `[memBuf, addr+i, byte_i]` before
  `SETITEM` (mirror `emit_chunked_store_byte_at_local`). Regression: `(memory 1)`
  store+load round-trip executed in the harness, asserting the stored value.
- **T2 (`rem_s` MIN%-1):** guard both `i32`/`i64` const-fold closures in
  `op_numeric/divrem.rs` to return `0` for `MIN % -1`. Test: fold the literal
  pair, assert `0`.
- **T3 (`Return` clears stack):** truncate to the frame's `result_count`
  instead of `clear()`, matching `handle_branch`. Low-risk consistency fix.
- **C1 (Neo.Crypto.*):** remove `EXTENDED_SYSCALLS` and the `crypto_*` /
  `verify_with_ecdsa` aliases. Re-route hashing/verify to
  `System.Contract.Call(cryptoLibHash, method)`. The CryptoLib native contract
  hash must be resolved from the Neo N3 native contract table and defined as a
  single named constant, with a unit test asserting it equals the documented
  mainnet value (do **not** hand-copy a hash literal across call sites — resolve
  once, reference everywhere). Test: a contract calling `sha256` lowers to a
  `CALLT`/`System.Contract.Call`, not a dead syscall hash.
- **C2 (bogus method tokens):** delete the `else` branch in
  `infer_contract_tokens`. Only concrete `System.Contract.Call` literals
  produce tokens. Test: a module using only `System.Runtime.Log` produces zero
  method tokens.
- **C3 (manifest overload merge):** key `dedup_named_entries` on
  `(name, parameter-count)`. Test: an overlay adding an overload appends rather
  than overwrites.
- **C4 (stale HASH160 comment):** reword `neo_syscalls.rs:176-177` to point at
  CryptoLib only.
- **C5 (empty permissions):** when a `System.Contract.Call` or any method token
  is detected and no permission is declared, auto-insert a `*/*` wildcard and
  emit a build warning unless an overlay is present.

### 5.3 Phase A exit criteria
- All Phase A tests green (unit + exec + existing Neo Express smoke unchanged).
- The two formerly-structural memory tests now also execute via the harness.
- `cargo clippy --all-targets --all-features` clean on `wasm-neovm`.

## 6. Phase B — Devpack wasm32 completeness

**Crates:** `neo-syscalls`, `neo-runtime`, `neo-macros`, `neo-types`,
`neo-test`. **Findings:** D1–D6, D11–D17.

### 6.1 Syscall wasm-import strategy (D-5)
- Add byte-marshalling wasm imports mirroring `neo_storage_get_into`:
  `neo_runtime_notify_state(name_ptr, name_len, state_ptr, state_len)`,
  `neo_runtime_get_calling_script_hash_into(buf_ptr)`,
  `neo_runtime_get_entry_script_hash_into(buf_ptr)`,
  `neo_runtime_get_executing_script_hash_into(buf_ptr)`.
- Give every remaining public wrapper a dedicated import lowered by the
  translator to a real `SYSCALL`: `check_sig`, `check_multisig`,
  `verify_with_ecdsa`, `get_random`, `get_trigger`, `get_network`,
  `get_address_version`, `get_gas_left`, `burn_gas`, `get_notifications`,
  `current_signers`, `contract_call`, `create_standard_account`, `load_script`,
  iterator family. Translator side: extend the `neo::*` alias table so each
  resolves to the canonical `System.*` descriptor already hashed correctly.
- Remove the generic `default_value_for` wasm32 fallthrough for any wrapper that
  now has a real import. Keep a single, documented, tested matrix in
  `neo-syscalls` listing every public syscall and its lowering path.

### 6.2 Per-finding fixes

- **D1 (events):** `#[neo_event]::emit()` and `NeoVMSyscall::notify()` serialize
  the state array and forward it via `neo_runtime_notify_state`. Host path
  unchanged. Test (exec): emitting a `TransferEvent` yields a Notify with the
  full arg array.
- **D2 (script hashes):** the 20-byte accessors use the `_into` imports; deprecate
  the zero-returning variants (or remove under D-3).
- **D3 (syscall stubs):** subsumed by 6.1. Add a compile-test (`tests/syscall_coverage.rs`)
  that asserts every public wrapper resolves to a lowered import (no default
  fallthrough) for the security-critical set.
- **D4 (export types):** extend `argument_conversion` /
  `parse_inner_output_kind` to marshal `NeoByteString` / `Hash160` / `NeoString`
  via ptr+len (in and out). Emit `compile_error!` with a helpful message for any
  unsupported type in a `#[neo_contract] impl`.
- **D5 (safe division):** add `NeoInteger::try_div`/`try_rem` →
  `NeoResult` mapping zero divisor to `NeoError::DivisionByZero`; document the
  operator fault behavior.
- **D6 (neo-test):** route `MockRuntime` through the `neo-syscalls` global
  `STORAGE_STATE`/`ACTIVE_WITNESSES` so it is the single source of truth; expose
  a `reset()`-aware harness; remove the need for ad-hoc `TEST_LOCK` (or
  document it as the supported pattern).
- **D11 (verify defaults):** `NeoCrypto` verification stubs default to **false**
  (secure), matching the syscall mock; prefer routing through `NeoVMSyscall`.
- **D12 (#[neo_method]):** standalone `#[neo_method]` either collects exports at
  module level **or** emits `compile_error!("#[neo_method] must be inside a
  #[neo_contract] impl")`. Fix the examples to use `#[neo_contract] impl`.
- **D13 (stateless structs):** wrappers no longer call `Contract::new()` then
  mutate; instead the macro documents/enforces that contract structs are
  stateless and all persistent state goes through `#[neo_storage]`. Lint: a
  field assignment in an exported `&mut self` method is a `compile_error!`.
  Rewrite `storage_contract`/`token_contract` examples to be storage-backed.
- **D14 (storage miss):** `host_get_into` returns `-1` for `Ok(None)` so host
  matches wasm `Missing` semantics; document the distinction.
- **D7 (NeoMap):** switch `remove` to insertion-stable `Vec::remove` and
  document that `NeoMap` is a linear map (on-chain NeoVM `Map` is key-sorted);
  add a test asserting iteration order stability across removes.
- **D8 (storage ambiguity):** `NeoStorage::get` returns
  `NeoResult<Option<NeoByteString>>`; deprecate the ambiguous form; steer
  authors to `storage_try_get`/`RawStorage`.
- **D9 (Hash160 Display):** `Display` emits big-endian (canonical); add
  `to_be_hex`/`from_be_hex` and base58 address helpers.
- **D10 (murmur32):** either implement Murmur3-x86-128 matching
  `Neo.Crypto.Murmur128` or rename/remove the bogus function.
- **D16 (NeoError):** add `source()` + `From<TryFromIntError>`/`From<ParseIntError>`;
  fix `PartialEq<String>`; remove/wire vestigial traits; replace glob re-exports
  with named modules.
- **D17 (exports ABI):** fold the per-export status into a packed `(value, code)`
  return rather than a second `<Name>LastError` export (reduces export table).

### 6.3 Phase B exit criteria
- `tests/syscall_coverage.rs` green (no default fallthrough for the
  security-critical set).
- A minimal NEP-17-style contract using `NeoByteString`/`transfer(from,to,…)` /
  `#[neo_event]` compiles, exports correctly, and its emitted notifications are
  validated by the exec harness.
- All examples either compile against the new macro semantics or are rewritten.

## 7. Phase C — Contract security sweep

**Dir:** `contracts/`. **Findings:** X1, X2, X3, X4, X5, X18, X14, X19, X20.

- Promote the ad-hoc `ensure_witness_i64` helper into `neo-runtime` as the
  canonical `NeoRuntime::require_witness_i64(id) -> bool` (one implementation).
- Apply it as the first guard on every state-changing entry point of:
  - `escrow` (configure/release/refund) — X1
  - `governance-dao` (configure/propose/vote/unstake) — X2, X3, X18
  - `nep11-nft` (transfer/mint) — X4
  - `nft-marketplace` (create_listing/cancel_listing) — X5
  - `flashloan-pool` (borrower witness even in the stub) — X20
- Host-test each guard using the Phase-B-consolidated witness mock (the same
  pattern timelock-vault uses today).
- **X14:** implement the multisig-wallet surface the README documents, **or**
  correct the README to match the real reader-only stub.
- **X19:** drop `supportedstandards` from nep17-token/nep11-nft sample
  manifests (or implement the required methods).

### 7.1 Phase C exit criteria
- Every state-changing entry point in the listed contracts has a witness guard
  and a passing auth test (accept-authorized / reject-unauthorized).
- No contract advertises a standard it does not implement; READMEs match code.

## 8. Phase D — Cross-chain: correct-or-fail-loud

**Crates:** `move-neovm`, `solana-compat`. **Findings:** X6, X7, X8, X9, X10,
X11, X12, X13, X17.

**Move (`move-neovm`):**
- **X6:** emit overflow-check sequences for Add/Sub/Mul (op + compare +
  conditional `Unreachable`/abort); mask `CastU8` with `I32And 0xFF`; route
  `Div`/`Mod` through Move `Abort` on zero.
- **X10:** inject `Exists`-probe before `MoveTo` (abort on hit) and presence
  check before `MoveFrom` (abort on miss); wire `ResourceTracker` into the
  generated WASM.
- **X11:** `LdU128` `bail!("u128 constants unsupported")` (loud) — do not
  truncate.
- **X12:** lower `Pack/Unpack/BorrowField/Vec*` to explicit
  `bail!("unsupported Move feature: …")` at translation time instead of runtime
  `Unreachable`.
- **X17:** replace `DefaultHasher` resource keys with a fixed, versioned digest
  (FNV-1a or SHA-256 prefix); freeze the scheme in a constant + test.

**Solana (`solana-compat`):**
- **X8:** `entrypoint!` deserializes the account stream (key + owner + lamports
  + data-len + data + flags) into `AccountInfo`s before calling
  `process_instruction`; `next_account_info` works for real.
- **X9:** `storage_read` fills the caller's buffer via a new
  `neo_storage_get_into(ptr, max_len)` host import.
- **X13:** `sol_get_clock_sysvar` divides `System.Runtime.GetTime` by 1000 to
  yield seconds; document the unit.
- **X7:** `sol_verify_signature` becomes `compile_error!` /
  `unimplemented!("Ed25519 verification requires a host bridge not yet wired")`
  — never silently returns a witness-probe as a valid signature.

### 8.1 Phase D exit criteria
- Move arithmetic overflow traps; resources abort on duplicate/absent;
  unsupported features bail at translation; resource keys are stable across
  runs (test).
- Solana `entrypoint!` receives the right number of accounts; `storage_read`
  fills buffers; clock is in seconds; `sol_verify_signature` fails to compile
  with a clear message.

## 10. Cross-cutting

### 10.1 Verification strategy
- Every fix lands with a test that would fail without the fix. Wherever the
  fix changes generated/emitted bytecode or syscall behavior, the test uses the
  **exec harness** (Phase A) or Neo Express — not opcode-shape matching.
- Phase A's exec harness is the substrate for B/D behavioral tests.

### 10.2 Commit & CHANGELOG strategy (autonomous)
1. **First commit:** the existing uncommitted WIP (timelock witness/time,
   NEF `_`-prefix/128 limits, chunked-load sign-extension + its test) — already
   validated, folded in as the baseline.
2. **Thereafter:** one atomic commit per finding = `{fix} + {test}`, `cargo
   test` green before the next. Commit message references the finding ID
   (e.g. `fix(compiler): T1 correct memory store SETITEM operand order`).
3. **Phase boundary:** CHANGELOG entry summarizing the phase; bump version only
   at the very end (next minor, since breaking changes land).

### 10.3 Risks
- **Exec harness bugs** could give false confidence → mitigated by cross-checking
  canonical scripts against Neo Express and unit-testing the executor itself.
- **Breaking macro changes** could diverge examples → mitigated by rewriting
  examples in-lockstep and enforcing via CI build-all-contracts (Phase E).
- **Translator lowering of new devpack imports** must stay in sync with the
  `neo::*` alias table → mitigated by the syscall-coverage compile-test (D3).

## 11. Definition of done
- All Critical (Tier-1) and High (Tier-2) findings resolved or explicitly
  documented-as-deferred with a tracked issue.
- `cargo test --workspace` green; `cargo clippy --all-targets --all-features`
  clean; `cargo fmt --all --check` clean.
- CHANGELOG updated; version bumped to next minor.
- This spec's exit criteria met for every phase that ran.
