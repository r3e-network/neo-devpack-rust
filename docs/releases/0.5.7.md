# Neo LLVM v0.5.7 Release Notes

Release date: 2026-06-18

## Highlights

- Prepared a production-focused Rust Neo N3 contract release: Rust contracts can
  compile to Wasm, translate to NEF, deploy, and execute on Neo Express with the
  updated devpack/runtime path.
- Published release metadata for `wasm-neovm` `0.5.7` and the devpack crate
  family `0.1.1`.
- Reduced storage-heavy contract NEF pressure by keeping common storage,
  runtime, notification, timestamp, and script-hash flows off the heap-heavy
  `NeoValue` path.
- Added a storage smoke contract and expanded Neo Express validation so storage
  behavior is tested against real contract storage instead of only host-side
  simulation.
- Added a system guide for Rust -> Wasm -> NeoVM development, validation, size
  analysis, and troubleshooting.

## What Changed

### Added

- `RawStorage` byte-slice APIs, `RawKeyBuilder`, and direct `i64` key/value
  storage helpers in `neo-runtime`.
- Translator runtime helpers for `neo_storage_*`, direct `raw_storage_*`,
  lightweight runtime log/notify, timestamp, and script-hash imports.
- `contracts/storage-smoke` for real Neo Express storage round-trip validation.
- Detailed documentation in `docs/rust-neo-n3-system-guide.md`.

### Changed

- `wasm-neovm` now releases as `0.5.7`.
- `neo-types`, `neo-syscalls`, `neo-runtime`, `neo-macros`, and `neo-devpack`
  now release as `0.1.1`.
- Contract examples declare versioned local `neo-devpack` dependencies so cargo
  can package them consistently for registry-oriented workflows.
- Storage-heavy examples were refactored onto compact raw storage/runtime paths.
- Rendered manifests clear `features` for Neo Express compatibility.

### Fixed

- Host and Wasm storage behavior now preserve the difference between explicit
  missing storage and empty stored byte strings where the runtime can expose it.
- Primitive Rust method argument/return types now render as Neo manifest
  `Boolean`/`Integer` instead of falling through to `Any`.
- Event macro emission on `wasm32` no longer forces heap-heavy state assembly
  for simple event notifications.
