# Neo LLVM v0.5.8 Release Notes

Release date: 2026-06-18

## Highlights

- Corrects the release version policy so every public workspace crate uses the
  same version number.
- Moves the devpack crate family, `move-neovm`, `neo-solana-compat`,
  `neo-test`, `wasm-neovm`, integration metadata, and contract templates onto
  `0.5.8`.
- Hardens version checks so future releases fail if any crate drifts back to a
  separate version line.

## What Changed

### Unified Versioning

- `workspace.package.version` is now the source of truth for all workspace
  packages.
- Workspace packages use `version.workspace = true` instead of independent
  `version = ...` entries.
- Internal workspace dependency pins in the root `Cargo.toml` all use `0.5.8`.
- Contract templates under `contracts/` use package version `0.5.8` and pin
  local devpack compatibility dependencies to `0.5.8`.

### Release Tooling

- `scripts/check_versions.sh` now validates workspace packages, internal
  dependency pins, and contract templates.
- `scripts/publish-to-cratesio.sh` now includes `neo-test` and `move-neovm` in
  the default release crate list.

## Verification

The following checks were used for this correction release:

- `bash scripts/check_versions.sh`
- `cargo fmt --all --check`
- `cargo check --workspace`
- `make test`
- `make package-check`
- `scripts/publish-to-cratesio.sh --dry-run`

## Release Note

Version `0.5.7` was already published to crates.io with the older split-version
policy. Because published crates.io versions are immutable, `0.5.8` is the
corrective release that establishes a single version line for the full Rust Neo
N3 toolchain.
